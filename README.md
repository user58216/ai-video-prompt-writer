# AI Video Prompt Writer（AI 视频提示词扩写师）

把**一句话视频创意**扩写为可直接复制给 AI 视频生成工具（Muse、可灵、即梦等）的**多段专业提示词**。

这是一个 TeleAgent / Claude 类 AI 助手可加载的 Skill（技能包）。安装后，你对助手说"我想生成一个××视频"，它会自动完成专业的分段提示词设计。

## 核心能力

- **极其真人写实（默认风格）**：真实皮肤纹理、自然光线、自然人体运动，默认不使用电影调色与戏剧化光影
- **严格保留用户创意**：人物、服装、地点、剧情、情绪、时长一律不擅改，不擅自加对白/音乐/字幕
- **多段连续性设计**：人物锁定不换脸、服装状态规则、道具生命周期台账、光线单调递进，每段独立可复制
- **空镜呼吸段**：开场定基调、章节过渡、MV 补时、首尾呼应
- **歌曲 MV 全曲分段**：核实歌曲时长 → 计算段数 → 映射歌曲结构 → 副歌对齐情绪点，附剪辑对位总表

## 文件结构

```

└── references/
    ├── continuity-techniques.md      # 多段连续性核心技术（人物锁/道具台账/光线递进/自检清单）
    ├── prompt-templates.md           # 单段提示词模板/人物设定卡/镜头与动作链写法/负面提示词分类库
    ├── mv-song-workflow.md           # 歌曲 MV 全曲分段流程
    └── examples.md                   # 实战案例骨架（一句话→5段；整首歌→27段）
```

## 安装（TeleAgent）

1. 下载本仓库，将 `ai-video-prompt-writer` 文件夹放入技能目录（`skills/`）；
2. 重启或刷新技能列表，在【技能】中启用「AI视频提示词扩写师」。

其他 AI 助手（Claude Code 等）也可直接把本文件夹放入对应的 skills 目录使用。

## 使用方式

对启用技能后的助手说：

- 「生成视频提示词：黄昏海边散步，5 段 × 10 秒」
- 「把这首歌整首做成 MV 分段提示词」
- 「视频接不上，帮我修连续性」
- 「人物不一致 / 换脸了，重新写」

输出固定为四部分：**简短说明 → 统一设定 → 分段提示词（每段独立可复制）→ 拼接建议**。

每段提示词包含：时长、连续性要求、人物状态、场景光线、前/中/远景环境、动作链（每 10 秒 ≤3 个有因果的动作）、镜头（机位+距离+景别+运动）、真实环境音、按场景挑选的负面提示词。
