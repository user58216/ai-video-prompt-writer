# 案例骨架

两个经过实际验证的案例结构，供快速对照。只给结构与要点，具体文字按模板重新生成。

## 案例 A：一句话创意 → 5 段短片

输入（示意）："黄昏海边散步，5 段 × 10 秒"

结构：

| 段 | 内容 | 作用 |
|---|---|---|
| 1 | 人物入画走向海边 | 建立段：锁定人物/服装/光线基准，产出全片参考帧 |
| 2 | 沙滩行走：观察远处 → 放慢脚步 | 动作链开始 |
| 3 | 发现细节（脚印/贝壳）：放慢 → 蹲下拾起 | 因果动作 |
| 4 | 看物品 + 望海：静止情绪段 | 情绪落点，动作最少 |
| 5 | 收起物品起身，继续走远，背影渐小 | 收尾 |

要点：

- 光线全程黄昏渐暗，单调递进
- 外套/包/鞋逐段重复描述，绝不写"同上"
- 第 1 段人物最清晰帧 = 全片人物参考
- 每段动作 ≤3 个、有因果

## 案例 B：整首歌 → 27 段 MV（约 4 分 30 秒）

流程：搜索核实歌曲与时长 → 27 段 = 4:30 ÷ 10s → 设计单晚连续叙事 → 映射歌曲结构：

| 歌曲位置 | 用段 | 内容 |
|---|---|---|
| 前奏 | 1-2 | 空街开场、主角赴约 |
| 主歌一 | 3-5 | 到店等待、铺垫关系 |
| 副歌一 | 6-8 | 三人同桌（情绪点一：自己的位置） |
| 间奏一 | 9-10 | 玻璃倒影空镜 + 门口道别 |
| 主歌二 | 11-13 | 无声付出（递东西、目送两人走远） |
| 副歌二 | 14-16 | 打了又删的消息、隔街目送相拥（情绪点二：心碎） |
| 间奏二 | 17-18 | 低头转身 + 红绿灯空镜 |
| 副歌三 | 19-21 | 独行长街、路灯抬头、天桥 |
| 副歌四 | 22-24 | 末班车、车窗倒影、到站 |
| 尾奏 | 25-27 | 楼道声控灯、亮起的窗、首尾呼应空镜 |

要点：

- 单晚叙事（傍晚→深夜）保证服装与光线一致，光线台账：傍晚橙粉 → 暮色 → 店内暖光 → 路灯 → 深夜
- 道具生命周期跨段管理：礼品袋第 2-12 段、热饮纸杯第 14-24 段、手机第 3/8/14 段
- 空镜 4 段（1、9、18、27），其中开场与结尾同一条街首尾呼应，空镜可循环补时
- 副歌起点对齐情绪段；末段预留 2-3 秒给歌曲收尾
- 先生成 3 个关键段（人物基准段 + 两个情绪点段）验证人物一致性，再铺全片

## 从案例迁移到新需求的要点

1. 用户给的要素乱序时，先重排成自然时间线再分配到段落
2. 段数不够时优先压缩"过场"（行走、下车），保住情绪点段落
3. 一致性出问题时，先减镜头运动，再强化首尾帧描述
4. 用户只给一句话时，参照案例 A 的"一天缩影"结构自行补全环境与动作
