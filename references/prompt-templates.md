## 1. 单段提示词完整模板

每段独立可复制，结构固定：

```
### 第 N 段｜时间 · 地点 · 动作要点　X 秒

> **连续性**：与第 N-1 段的关系（直接延续/时间蒙太奇）+ 继承的结束状态 + 人物一致声明。
>
> [一段式完整提示词]
>
> **负面提示词**：按场景挑选 4-8 条。
```

一段式提示词内部顺序：

**风格声明 → 时间地点光线 → 人物全描述 → 动作链 → 环境（前景/中景/远景）→ 镜头 → 声音**

示例骨架（校园晨景）：

> 极其真人写实的实拍视频（photorealistic live-action footage, documentary-style realism）。凌晨六点，中国某普通公立高中校园，天刚亮，光线柔和平淡。一名 17 岁左右中国高中男生，黑色短发学生头自然碎发，长相普通真实、皮肤有真实毛孔与细微瑕疵，身材偏瘦匀称，穿着蓝白配色宽松运动款校服外套（拉链拉到胸口）、深蓝色校服长裤、白色普通运动鞋，背着深蓝色双肩书包，从画面左侧自然步行进入，朝教学楼方向走，途中略微放慢脚步抬头看了一眼亮灯的教学楼，随后继续向前走。前景是水泥路面与零星落叶；中景是米黄色教学楼、旗杆、几棵树；远景是淡色晨空与教学楼轮廓。摄影机固定于校园路上，中景偏全景，构图稳定，轻微手持呼吸感。真实环境声：清晨鸟叫、远处模糊的早读声、脚步声、微风。

## 2. 人物设定卡模板

- 主角卡字段：年龄/国籍 → 面部 → 发型发质 → 身材身高 → 服装（外套+内搭+裤+鞋）→ 随身包袋 → 道具 → 气质
- 反例：❌ "一个年轻男孩穿着卫衣"
- 正例：✅ "一名 20 岁左右的中国男孩，黑色短发自然蓬松，身材匀称偏瘦，穿着宽松的灰色连帽卫衣、深色休闲长裤和普通运动鞋，背着一个深色吉他包"
- 配角卡：凡出现 ≥2 段即建卡；只在单段出现的路人可模糊处理（"几名穿同款校服的同学，面容自然随机"）。

## 3. 动作链写法

- 每 10 秒 ≤3 个动作，动作间有因果：行走 → 放慢 → 驻足 → 观察 → 收起 → 继续行走。
- 禁止：重复回头/微笑/眨眼/点头；无因果的动作切换；一段内塞过多动作；像演员一样刻意表演。
- 情绪用微小动作外化：抿嘴、呼出白气、握紧、低头两秒、脚步放轻——不直接写"很伤心""很开心"。

## 4. 镜头描述写法

五要素：机位方位（侧后/正后/街对面）+ 距离（约 3 米）+ 景别（近景/半身/中景/全景）+ 运动方式（固定/同速跟随/极缓推近/缓慢横移）+ 目的。

- 反例：❌ "镜头跟随人物"
- 正例：✅ "摄影机位于人物左后方约 3 米，以相同步速自然跟随，保持中景构图，能看到人物上半身与周围环境"
- 原则：少切换、缓运动、镜头服务故事；拿不准时用固定机位最安全；每段镜头变化不超过一次。

## 5. 负面提示词分类库

按场景挑 4-8 条，不要每段机械全塞：

- **通用**：AI 生成感、动漫、CGI、画面闪烁、字幕、水印、背景音乐、旁白
- **人物**：塑料皮肤、过度磨皮、网红脸、偶像化美貌、夸张表情、机械动作、身体僵硬、人物变脸、服装/发型/身材变化
- **手部**：手指畸形、手部异常
- **道具**：道具变形、道具消失、手指穿模、物体穿模
- **镜头**：不必要的运镜、突然推拉、慢动作、极端特写
- **光线/场景**：电影级调色、戏剧化光影、光线突变、场景突变、时间跳变
- **文字**：清晰文字、乱码招牌、聊天界面细节（AI 生成文字易崩，一律让屏幕内容模糊不可读）

## 6. 声音设计速查

按场景选 2-4 种真实环境音，声音不喧宾夺主：

- 街道：脚步、远处车流、风
- 校园：早读声、篮球拍地、走廊人声、蝉鸣
- 店铺：冰柜嗡嗡、门口提示音、碗筷轻碰
- 公交/车内：行驶低频声、隐约报站、安静空气感
- 楼道：脚步回声、声控灯电流轻响

用户要求人物说话时，才明确对白内容、语言、语气与口型要求。
